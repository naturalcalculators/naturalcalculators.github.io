Statistics and regression

Type your data into a table once, then ask for any statistic you like — averages, spreads, and the line or curve that fits best.

Getting into STAT mode

Press MODE 3. The calculator asks what kind of statistics you want:

PressTypeFits
11-VAROne list of numbers — averages and spread, no fitting
2A+BXA straight line, y = A + Bx
3_+CX²A parabola, y = A + Bx + Cx²
4ln Xy = A + B ln x
5e^Xy = A eBx
6A·B^Xy = A·Bx
▼ 7A·X^By = A·xB
▼ 81/Xy = A + B⁄x

A STAT marker appears at the top of the display. Changing to another mode throws the data away, so finish with it first.

The ln X, e^X, A·B^X and A·X^B fits work through logarithms, so they need positive data — positive x for ln X and A·X^B, positive y for e^X, A·B^X and A·X^B. A zero or negative value there gives Math ERROR.

Entering data

You land straight in a table. Type a value and press =; the value drops into the table and the cursor moves down a line. Keep going until the list is done. Anything that works out to a number will do, so 1÷3 or √2 is fine as an entry.

For the two-variable types the table has an X and a Y column. The easy way: type every X value first, then press ▶ to move to the Y column, ▲ back up to line 1, and type the Y values the same way.

  • ▲ ▼ ◀ ▶ move around the table. Typing over a cell and pressing = replaces it.
  • DEL on a line (with nothing typed) deletes that whole line.
  • SHIFT 1 2 (Edit) gives Ins, a new blank line above the cursor, and Del-A, which empties the whole table.
  • AC leaves the table. The data stays; SHIFT 1 2 (Data) opens it again.
One value per line. There is no frequency column, so a value that occurs three times is typed in three times. And a line left blank is never quietly treated as 0 — every statistic gives Math ERROR until you fill it in or delete it.

Reading the results

With the table closed, SHIFT 1 (STAT) opens the menu. Pick a group, then the value you want, and it is typed into the line like any other number — press = to see it, or keep calculating with it.

PressGroupHolds

Which standard deviation?

xσn divides by n: use it when your numbers are the whole population. xσn−1 divides by n−1: use it when they are a sample and you want to estimate the spread of the population they came from. Most statistics courses want xσn−1 unless told otherwise.

Example: a line of best fit

MODE 3 2 (A+BX). Enter X as 1 2 3 4 5 and Y as 2 4 5 4 5, then AC.

You pressYou get
SHIFT 1 5 1 =  (A, the intercept)11⁄5 = 2.2
SHIFT 1 5 2 =  (B, the slope)3⁄5 = 0.6
SHIFT 1 5 3 =  (r)√15⁄5 = 0.7745966692
6 SHIFT 1 5 5 =  (ŷ at x = 6)29⁄5 = 5.8
5 SHIFT 1 5 4 =  (x̂ for y = 5)14⁄3 = 4.666666667

So the line is y = 2.2 + 0.6x. Note that the value goes before ŷ and x̂, the way it does on the real calculator: 6ŷ reads “the y predicted at 6”.

r runs from −1 to 1. Near 1 or −1 the points sit close to the line; near 0 the line tells you very little.

Example: a curve

MODE 3 3 (_+CX²). X: 0 1 2 3, Y: 1 2 5 10. The fit comes back as A = 1, B = 0, C = 1 — the data is exactly y = 1 + x². A parabola usually meets a given height twice, so the quadratic Reg menu has two estimates: 5x̂₁ gives 2 and 5x̂₂ gives −2, and 4ŷ gives 17.

A good r does not make a good model. Try a few different types on the same data and compare r, but also plot the points if you can. A curve can fit five points beautifully and still predict nonsense outside them.
