Binary, hex and octal

Whole-number arithmetic in base 10, 16, 2 or 8, conversions at one keypress, and the logic operations programmers use.

Getting into BASE-N mode

Press MODE 4. The display shows Dec at the top: you are working in ordinary decimal, but only with whole numbers.

Switching base

Four keys carry a green label for this mode, and in BASE-N you press them directly, with no SHIFT:

KeyBase255 shows as
x²DEC — decimal, base 10255
x■HEX — hexadecimal, base 16000000FF
logBIN — binary, base 20000000011111111
lnOCT — octal, base 800000000377

Pressing one with an answer on screen converts that answer, so converting is just: type the number, =, then the base you want.

Hex digits

The digits A to F are the red letters on the second row of function keys, and in BASE-N you press those keys directly as well: (−) is A, °′″ is B, hyp is C, sin is D, cos is E and tan is F. In HEX, FF + 1 gives 00000100.

Only the digits that exist in the current base are allowed: a 2 in a BIN calculation, or an 8 in OCT, gives Syntax ERROR.

Logic operations

SHIFT 3 (BASE) gives the bitwise operations. Working in decimal, 12 is 1100 in binary and 10 is 1010:

Mixing bases in one line

On the second page of the BASE menu (SHIFT 3 ▼) are the prefixes d h b o, which mark a single number as decimal, hex, binary or octal whatever base you are in. In decimal, hFF + b101 gives 260 (255 + 5).

What is different from normal maths

  • Whole numbers only. Division drops the remainder: 7 ÷ 2 is 3, and −7 ÷ 2 is −3. Keys that only make sense for fractions — the decimal point, √, fractions, logs to a base — do nothing here.
  • 32 bits. Numbers run from −2147483648 to 2147483647. Going past either end is a Math ERROR, never a silent wrap-round.
  • Negatives in two's complement. −1 in HEX is FFFFFFFF, which is how a computer stores it.
  • Binary shows 16 bits, so BIN only covers −32768 to 32767. Converting 40000 to BIN is a Math ERROR; it is fine in DEC, HEX and OCT.

Memories A–F still work through ALPHA and RCL; pressing the letter keys on their own types hex digits. MODE 1 goes back to normal calculations.
