Matrices

Up to three matrices of up to 3×3, with determinants, inverses, transposes and powers — and the fastest way to solve simultaneous equations.

Setting up a matrix

Press MODE 6. The calculator asks which matrix (1 MatA, 2 MatB, 3 MatC) and then its size, rows × columns:

PressSizePressSizePressSize
13×342×3▼ 71×3
23×252×2▼ 81×2
33×162×1▼ 91×1

The matrix appears as a table of zeros. Type each element and press =: the cursor moves right along the row, then on to the start of the next row, so you can type a whole matrix row by row without touching the arrows. Use the arrow keys to go back and change an element. AC leaves the table, and the matrix is kept.

For a second matrix, press SHIFT 4 (MATRIX) 1 (Dim), pick it and give it a size. SHIFT 4 2 (Data) reopens one you have already made.

The MATRIX menu

SHIFT 4 is where everything is:

PressGives
1 Dim / 2 DataSize a matrix / edit one

6MatAns, the last matrix answer
▼ 7det( — the determinant
▼ 8Trn( — the transpose, rows swapped for columns

The ordinary keys do the rest: + − × between matrices, a number × a matrix to scale it, x⁻¹ for the inverse, x² and SHIFT x² (x³) for powers, and SHIFT hyp (Abs) for the size of every element.

Order matters. MatA × MatB and MatB × MatA are different matrices, as the table shows. Matrix multiplication is not like multiplying numbers.

Reading a matrix answer

A matrix answer fills the display as a table, labelled Ans. One element is highlighted and shown in full on the bottom line — exactly, so 3⁄2 stays a fraction until you press S⇔D. Move the highlight with the arrow keys to read the others.

Press an operator to carry on from the answer: × 2 gives MatAns×2. The answer is also kept as MatAns in the menu, for later.

Solving simultaneous equations

This is what most people want matrices for. Write the equations as A x = B, and the answer is x = A⁻¹B.

For 2x + y = 5 and x + 3y = 10:

  1. MatA is the 2×2 of coefficients: 2 1 1 3.
  2. MatB is the 2×1 of right-hand sides: 5 10.
  3. Type MatA⁻¹ × MatB and press =.

The answer is [[1], [3]]: x = 1, y = 3.

Three unknowns work the same way with a 3×3 and a 3×1. For x + y + z = 6, 2y + 5z = −4 and 2x + 5y − z = 27, MatA is 1 1 1 0 2 5 2 5 −1 and MatB is 6 −4 27; MatA⁻¹ × MatB gives [[5], [3], [−2]].

If the inverse is a Math ERROR, the determinant is 0 and the equations have no single answer — either no solution or infinitely many. Check with det(MatA).

When sizes do not fit

Matrices only combine when their sizes allow it, and the calculator says so rather than guessing:

  • + and − need the same size on both sides.
  • × needs the columns of the first to equal the rows of the second: a 2×3 times a 3×2 is fine (and gives a 2×2), a 2×3 times a 2×3 is not.
  • det, inverse and powers need a square matrix.

Break those and you get Dimension ERROR. A matrix plus a plain number, or sin of a matrix, is a Syntax ERROR. See errors.

Leaving MATRIX mode with MODE clears all three matrices.
