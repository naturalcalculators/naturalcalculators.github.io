Scientific notation and the E

Why a perfectly ordinary calculation suddenly comes back as 1.219325915×10¹⁴, and how to type numbers like that yourself.

Reading the answer

When a result is too long to show in full, it is written in scientific notation: one digit, a decimal point, the rest, and then a power of ten telling you where the point really belongs.

1.219325915×10¹⁴ means: take 1.219325915 and move the decimal point fourteen places to the right. That is about 122 trillion.

A negative power moves it the other way. 1.2×10⁻⁵ is 0.000012 — the point moves five places left.

On many calculators this is shown as 1.2E−05. The E stands for exponent and means exactly the same thing: “times ten to the power of”. It is not the number e from natural logarithms, and it is not an error message. This calculator writes it out properly as ×10 with a raised power, which is harder to misread.

Typing it yourself

Use the ×10■ key, not a multiplication sign and a power. Type 2.5, press ×10■, type 12: that is 2.5×10¹², in three keystrokes.

For a negative exponent, press (−) — the one in brackets, not the subtraction key — before the number. The subtraction key would ask the calculator to take something away instead.

Doing it the long way, 2.5 × 10 x■ 12, gives the same answer but takes more presses and leaves more room for the exponent-box mistake.

Why an answer switches to it without being asked

Because there is not enough room. The display shows ten significant digits. A number needing more than that — very large or very small — has to be written as a power of ten or not written at all.

The threshold is a display setting, not a property of the number. In SETUP (SHIFT MODE) you will find:

  • Norm — normal. Switches to scientific notation only when it has to.
  • Sci — always scientific, to a number of significant figures you choose.
  • Fix — a fixed number of decimal places. Useful for money.

These change only how the answer is displayed. Full precision is kept internally, so a chain of calculations does not accumulate rounding error just because you set Fix 2.

The ENG key

ENG is scientific notation with a restriction: the exponent is always a multiple of three. That matters because the units engineers use come in steps of a thousand — milli, micro, nano, kilo, mega, giga.

So 0.000012 amps is more useful as 12×10⁻⁶, because 10⁻⁶ is “micro”, and you can read it straight off as 12 microamps.

Press ENG after an answer to step the exponent in threes. SHIFT ENG steps it back the other way. The value never changes — only where the decimal point is drawn.

Getting back to an ordinary number

If an answer shows as a power of ten and you wanted the digits, the answer is usually that there are too many digits to show. But two things help:

  • S⇔D toggles between exact and decimal forms, which sometimes gives you a fraction that is easier to read than either.
  • Scaling the problem yourself — working in millions, or in milliseconds — keeps the numbers in a range you can read directly.

Arithmetic in scientific notation

You can type numbers in this form and calculate with them normally. Speed of light times a hundred seconds is 3 ×10■ 8 × 100, giving 3×10¹⁰.

The useful habit from doing it by hand still applies: multiply the front parts, add the exponents. It is worth a rough mental check, because a mistyped exponent is off by a factor of ten and looks entirely reasonable on screen.
